# The Day I Was Born media

Place photos in this folder as `the-day-i-was-born-01.png`, `the-day-i-was-born-02.png`, etc. They are loaded automatically in numbered order.

The project video is `the-day-i-was-born-vid-01.mp4`. The sketch expects `background_music.wav` and `click_sound.wav` here.

The p5.js source is in `public/sketches/the-day-i-was-born/`.
