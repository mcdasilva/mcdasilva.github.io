# Mayra media

Place the project media here:
- `mayra-01.png`, `mayra-02.png`, etc.: photos, automatically loaded in numerical order.
- `mayra-vid-01.mp4`: documentation video; displayed at its original aspect ratio.
- `mayra_harp.wav`: music used by the supplied p5.js sketch.

The interactive source lives in `public/sketches/mayra/`.
