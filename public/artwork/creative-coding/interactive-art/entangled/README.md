# Entangled artwork

Category: Creative Coding. Subcategory: Interactive Art.

Use `entangled-01.png` for the project photo, Work-page thumbnail, and video poster. Use `entangled-vid-01.mp4` for the documentation video. Additional numbered PNG files in this folder appear in the project gallery automatically.

The supplied p5.js sketch lives in `public/sketches/entangled/`. Its portfolio wrapper is `components/EntangledExperience.tsx`, and it appears on `/work/entangled/` below the documentation video. Keep `entangled_points_sound.wav` and `entangled_scribbles_sound.wav` here for the sketch's original sound loops.
