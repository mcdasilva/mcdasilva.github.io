# The Day I Was Born

`sketch.js` contains the supplied p5.js animation. Its visual sequence remains intact. Audio URLs point to `public/artwork/digital-art/creative-coding/animation/the-day-i-was-born/`; missing audio fails gracefully.

`embed.js` connects the startable sketch to the shared portfolio window. It manages sound toggling, restart, touch input, and cleanup. `index.html` uses the same local p5.js libraries as the other creative coding projects. Text and media paths are defined in the project record in `data/site.ts`.
